RECOVERY

备份与恢复

选择备份、确认密码，页面会完成校验、停止服务与恢复；原数据会保留一份。

导入已有备份

支持 zip / 7z，最大 2 GiB。也可在远程存储页面下载远程备份。

恢复会覆盖当前密码库内容，并短暂停止密码库和备份服务。开始前校验备份，恢复前数据保留为 data.before-restore-*；启动失败时尝试回滚。

DIAGNOSTICS

诊断与状态

查看访问路径、容器与网络信息，检查备份的远程投递情况。

检查结果在“任务与日志”展示。诊断报告会标明未通过的检查，不会更改防火墙、DNS 或已有代理。

MAINTENANCE

卸载与清理

明确选择要移除的服务和是否删除数据，网页面板保持运行。

默认仅移除容器，配置与数据保留。不会卸载 Docker 或删除其他应用的网络。

卸载网页面板本身

在服务器终端执行 sudo vwp uninstall，按提示确认。它只移除面板，密码库和备份保留。

执行 sudo vwp 打开终端管理菜单，也可以选择进入原始 Bash 脚本。
