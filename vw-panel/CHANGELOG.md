# 更新日志

## 0.7.2

- 原脚本功能对照仅保留在面板设置底部。

- 主服务和备份服务操作统一放在页面顶部，状态与启用、升级、停止或暂停、卸载同排展示。
- 移除底部维护折叠区，应用提示复用顶部按钮，避免重复入口。
- 立即备份移到备份文件列表旁；手机端服务按钮按两列排列。

## 0.7.1

- 主服务与备份服务维护统一为设置页底部的折叠卡片。
- 每项维护操作展示影响说明与右侧操作按钮。
- 备份维护始终显示，不再因未发现容器而隐藏；不可用操作按状态禁用。

## 0.7.0

- 导航按主服务、备份服务、面板管理分组，当前组自动展开。
- 备份设置与文件恢复分为各自子菜单，恢复不受主服务启动状态限制。
- 服务维护与卸载从各自服务页面进入，面板卸载归面板设置。
- 启用备份前检查主服务配置；主服务未运行时使用完整部署流程先启动，失败则不继续启动备份。
- 主服务升级不再顺带升级备份容器。

## 0.6.9

- 网页卸载移除手动 DELETE 输入，使用明确范围和数据处理说明进行点击确认。
- 数据处理改为保留或永久删除两种选择，按卸载范围展示影响内容。
- 后端校验与原始 Bash 卸载流程保持不变。

## 0.6.8

- 官方推送仅在启用时显示凭据输入，关闭时收起，保存入口仍可操作。
- 添加 Bitwarden 官方凭据申请链接和填写说明。

## 0.6.7

- 日志服务选择、查看与自动刷新集中到任务日志卡片内部。
- 统一查看日志按钮，按照所选服务读取，日志任务自动展开输出。

## 0.6.6

- 合并备份与保护、备份与恢复为同一“备份与恢复”菜单。
- 备份计划、通知、WebDAV、本机文件、导入与恢复集中展示，配置与恢复默认折叠。
- 本机备份列表提供下载和选择恢复，移除重复文件列表。
- 兼容旧恢复链接，上传后自动选中备份并展开恢复表单。

## 0.6.5

- 备份服务操作集中到页面顶部的状态卡片，移除配置分组之间的零散按钮。
- 启用、立即备份与待应用提示集中展示，避免重复应用入口。
- 暂停与升级收进服务维护，按实际服务状态禁用不可用操作。

## 0.6.4

- 保存入口统一放在展开配置组内的右下角，折叠后一起隐藏。
- 基本信息与注册权限合并保存，权限选项可单独展开。
- 各配置组明确独立保存范围，保留测试与应用操作。

## 0.6.3

- 正常检测结果并入服务器环境选项括号，移除独立提示栏，检测按钮放在字段旁。
- 升级后依据页面与服务端构建差异刷新一次，保留有效登录，防止刷新循环。
- 保留已确认的升级目标，避免旧响应提前终止等待。
- 验证真实整页导航、内联结果及移动布局。

## 0.6.2

- 首次配置的服务器环境直接选中检测结果，已有反代默认复用，空闲入口默认新装。
- 显示接入类型供查看与手动调整，保留明确修改，不再由后续检测覆盖。
- 已保存的面板管理反代显示当前配置名称。

## 0.6.1

- 代理日志依据实际容器 / 宿主机服务与部署记录读取，不再默认查找 Caddy。
- 环境默认自动检测，给出复用或新装建议，多候选和不明确的占用需确认选择。
- 未过期会话跨升级重启保留，升级后自动重连；退出和密码重置继续撤销会话。
- 首次从旧版迁移可能需登录一次；后续升级可直接恢复有效会话。
- 增加日志来源、检测时序、登录持久化、HTTP 重启与浏览器回归检查。

## 0.6.0

- 分开选择新装反代或复用已有反代，新装支持 Caddy、NPM、Nginx。
- NPM 自动创建管理账号、配置密码库站点与 HTTPS，账号通过登录后的页面查看。
- Nginx 自动配置 HTTPS、Certbot 续期和证书加载，失败恢复活动配置。
- 代理日志适配新服务并隐藏初始化密码；卸载默认保留反代，可明确选择同时移除。
- 保留原始 Bash 快照，补充部署、接口、真实 Compose 和浏览器回归检查。

## 0.5.6

- 访问方式明确写出 Caddy，区分自动安装与使用已有代理。
- 自动检测代理容器和实际网络，单网络自动填入，多网络选择，保留手动输入。
- 新装 Caddy 前检查端口和容器名冲突；外部网络保存和部署前校验，不自动创建隔离网络。
- 增加检测接口认证、网络与冲突保护、浏览器表单与移动布局的回归检查。

## 0.5.5

- 版本卡片使用浏览器原生展开，不依赖更新检查完成。
- 移除自动焦点跳转和失焦关闭，检查中仍可展开与收起。
- 页面资源 URL 带版本号，增加暂停页面脚本时点击展开的回归检查。

## 0.5.4

- 版本检查增加 20 秒超时，显示失败原因并保留重试入口。
- 点击立即显示弹窗中的检查状态，失败时不展示旧结果的升级按钮。
- 增加真实鼠标点击、慢速响应、超时和重试恢复的浏览器回归检查。

## 0.5.3

- 登录后遇到认证错误先复核当前会话；有效会话可自动重试一次读取。
- 登录失效返回登录页，迟到的登录提示不再直接作为工作区错误展示。
- 写入操作不自动重复提交，增加刷新后重新登录的浏览器回归检查。

## 0.5.2

- 点击左下角版本号打开版本弹窗，显示当前版本、最新版本和更新状态。
- 有新版本时可选择“立即更新”，支持手动刷新、更新日志入口和移动端定位。
- 自动检查不主动展开弹窗；支持点击外部或 Escape 关闭。

## 0.5.1

- 刷新先检查会话，不再闪现登录页。
- 旧请求的迟到响应不再干扰新登录。
- 增加连接失败重试和 Cookie 无法保持的提示。

## 0.5.0

- GitHub 更新检测、校验及独立后台升级任务。
